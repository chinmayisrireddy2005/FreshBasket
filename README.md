# FreshBasket – Fresh Grocery Store Website

## About the Project

FreshBasket is a simple, classic, and user-friendly grocery shopping website designed to make it easy for customers to explore fresh fruits, vegetables, leafy greens, and dairy products in one place. The website features a clean design, attractive product photographs, and easy navigation for a smooth shopping experience.

## Features

* **Home Page:** Introduces FreshBasket with a clean layout and fresh grocery categories.
* **Account Creation:** Provides a form for users to enter their account details.
* **Login Page:** Offers a user login interface.
* **Vegetables Page:** Displays a variety of vegetables with product details and shopping options.
* **Offers Page:** Showcases offers on vegetables, fruits, leafy vegetables, and dairy products.
* **Shopping Cart:** Allows users to add products, adjust quantities, remove items, and view the total price.
* **Offer Countdown:** Displays a countdown timer for promotional offers.
* **Contact Us:** Provides a page for customer enquiries.
* **Responsive Design:** Supports different screen sizes.
* **Simple Navigation:** Makes it easy to move between website pages.

## Technologies Used

* **HTML5** – Structures the website pages.
* **CSS3** – Provides styling, colours, and layout.
* **JavaScript** – Handles interactive features such as the shopping cart and countdown timer.
* **Unsplash** – Provides real food photographs loaded online.

## How to Run

1. Download and extract the FreshBasket project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Click **Go Live** using the Live Server extension.
5. Explore the website using the navigation menu.

An internet connection is required to load online product photographs.

FreshBasket is currently a frontend website project. Account creation, login, and checkout are demonstration features unless connected to a backend. The demo checkout does not process real payments or submit real orders.
